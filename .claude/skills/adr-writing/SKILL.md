Create docs/adr/NNNN-short-title.md (increment NNNN):
- Status: Proposed | Accepted | Superseded by NNNN
- Context: forces, constraints, scale numbers
- Decision: one paragraph
- Alternatives: pros/cons each
- Consequences: positive, negative, follow-ups, how we will know it was wrong
One page. Link related specs.
